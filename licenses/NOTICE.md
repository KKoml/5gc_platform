The manuscript's 5GAD and gaming/office/video input-record citations must accompany later redistribution of those records. No source-corpus license is inferred from its presence on a laboratory disk. This release provides configuration references and measured experimental excerpts, not the original external trace corpus. Do not assume the free5GC software license grants unrestricted rights to third-party datasets.

The selected source is an implementation/reference snapshot, not a complete independently runnable installer. It omits credentials, subscriber secrets, keys/certificates, Git history, runtime binaries, external projects and full raw data. Site-specific configuration and dependencies are required to run it. Offline validation is distinct from runtime validation.
