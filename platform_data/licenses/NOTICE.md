# Attribution and redistribution scope

The upstream free5GC license is retained in `free5GC-LICENSE` for attribution continuity. This review directory contains no platform source. Upstream components cited in Appendix A are free5GC, UERANSIM, K3s, gtp5g, Wireshark/tshark and Linux networking facilities; their respective license obligations remain applicable to a future code release.

The 5GAD, gaming, office and video input records require their original citations and redistribution rights. Their presence on a laboratory disk or in a private owner backup does not establish permission for public redistribution. The free5GC software license does not license third-party datasets. This directory provides measured experimental excerpts and configuration/provenance references; no new blanket dataset license is inferred.
