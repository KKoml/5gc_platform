# 5 s Data Example

[illustrative_D06_first20_rows.csv](illustrative_D06_first20_rows.csv) contains twenty contiguous rows from the D06 core-observation table. It provides a small example for inspecting field names, timestamps, and missing values.

[read_sample.py](read_sample.py) reads this example. Full run tables are available under [task_data/data/](../task_data/data/README.md); use those tables and the corresponding task indices for evaluation.
