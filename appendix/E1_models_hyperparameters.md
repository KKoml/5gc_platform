# Appendix E.1 — Models and hyperparameters

`manifests/fit_records.csv` extracts models, seeds, executed/selected epochs, parameter counts, status, and complete records from actual training records. Its hashes identify curated copies; original program hashes inside those records identify their own sources, not adapted files. `selected_prediction_models.csv` lists the actual D05 winner for each target. A configured candidate alone does not establish execution.

Normal-only detection still uses labeled D05 data to calibrate thresholds; the full procedure is not entirely unsupervised. Candidates include positive infinity and every finite D05 score. Among candidates satisfying the actual FAR budget, selection maximizes hits, minimizes false alarms, then favors the higher threshold. D06/D07 thresholds are fixed, without test normalization or point adjustment. No-alarm and missed-event results are retained.

The historical verification environment was Python 3.10.12, NumPy 2.2.6, pandas 2.3.2, PyArrow 21.0.0, scikit-learn 1.7.1, SciPy 1.15.3, XGBoost 3.0.4, PyTorch 2.11.0+cu128/CUDA 12.8, and NVIDIA RTX PRO 6000 Blackwell. The separate environment for saved-statistic checks is recorded in `checks/current/environment.json`. Historical neural inference/training used CUDA; CPU fallback is unverified.
